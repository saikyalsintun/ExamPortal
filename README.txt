CHINESE EXAM PORTAL — FIXED FILES

Files:
- index.html: portal page
- app.js: registered-name routing
- style.css: portal design

Install:
1. Put these three files in the same root folder as your portal homepage.
2. Keep each student's exam folder beside them.
3. Confirm the folder names and paths match the routes in app.js:
   Khaing/index.html
   Su/index.html
   Nyein/index.html
   Htun Mya/index.html

The Htun Mya path is URL-encoded as Htun%20Mya/index.html to support the space in the folder name.

IMPORTANT:
This package only contains the portal, not the student exam pages. Do not replace a student's exam index.html with the portal index.html.
